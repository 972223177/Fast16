## 1. 总体主流程（端到端）

```mermaid
flowchart TD
    A["打开 App"] --> FB{"首次启动?"}
    FB -- 是 --> OB["像素风弹窗<br/>什么是 8:16 饮食法"]
    OB --> B{"今日有计划?"}
    FB -- 否 --> B
    B -- 否 --> C["新建计划<br/>输入早餐时间(默认=现在)"]
    B -- 是 --> H["今日首页"]
    C --> D["推理午/晚候选方案"]
    D --> E["选取方案 + 逐餐微调"]
    E --> F["生成计划<br/>持久化 + 排程提醒"]
    F --> H
    H --> I{"prep / eat 时刻到?"}
    I -- 餐前准备 --> J["通知+轻短震动<br/>角色「备餐」+ 气泡"]
    I -- 开始吃 --> K["通知+轻短震动<br/>角色「进食」+ 气泡"]
    K --> L["用户打卡"]
    L --> M["写 check_ins<br/>记录页(统计+日历) / Widget 刷新"]
```

## 2. 首次启动引导（8:16 说明）

```mermaid
flowchart TD
    S["启动 / 清除数据后"] --> C{"onboarding_seen == false?"}
    C -- 是 --> D["弹像素风弹窗<br/>什么是 8:16 饮食法"]
    D --> X{"用户操作"}
    X -- 点「知道了」 --> SAVE["置 onboarding_seen = true"]
    X -- 返回键 / 点外部 --> SAVE
    SAVE --> M["进入主流程"]
    C -- 否 --> M
    M --> R["(设置页可重看说明)"]
```

> 说明：弹窗文案只做客观解释，不做医疗功效承诺；跳过也视为已读（`onboarding_seen = true`），不强拦。

## 3. 新建计划流程

```mermaid
flowchart TD
    S["进入新建计划"] --> I["输入早餐时间 B<br/>默认 = 当前时间"]
    I --> BC["(可选) 自动打卡早餐<br/>默认开"]
    BC --> G["生成 3 套候选<br/>均衡 / 午餐偏早 / 晚餐偏晚"]
    G --> P["用户选一套"]
    P --> A{"需要微调?"}
    A -- 否 --> CF["确认生成"]
    A -- 是 --> T["调午/晚时间 + 备餐时长"]
    T --> V{"约束校验通过?"}
    V -- 否 --> E["像素提示：红框闪烁 + 文案"] --> T
    V -- 是 --> CF
    CF --> W["写 meal_plans + meals"]
    W --> SC["排程所有 PREP / EATING 闹钟"]
    SC --> D["进入今日首页"]
```

> 说明：早餐默认「记录即打卡」（记录早餐时间 = 已开始吃），故早餐无 PREP 阶段、备餐默认 0；该自动打卡可关。

## 4. 时间推理算法（候选生成）

```mermaid
flowchart TD
    IN["B = 早餐时间<br/>W = 8h · minGap = 3h · bufferEnd = 30m"] --> WIN["窗口 = [B, B+W]"]
    WIN --> L["弹性 L = W − bufferEnd − minGap"]
    L --> C1["方案1 · 均衡<br/>lunch = B + W/2"]
    L --> C2["方案2 · 午餐偏早<br/>lunch = B + minGap + 0.25L"]
    L --> C3["方案3 · 晚餐偏晚<br/>lunch = B + minGap + 0.75L"]
    C1 --> D1["dinner = min(B+W−bufferEnd,<br/>lunch + minGap + 0.5L)"]
    C2 --> D2["dinner = lunch + minGap"]
    C3 --> D3["dinner = B + W − bufferEnd"]
    D1 --> O["输出 3 套候选"]
    D2 --> O
    D3 --> O
```

## 5. 餐次状态机

```mermaid
stateDiagram-v2
    [*] --> SCHEDULED
    SCHEDULED --> PREPARING : prep 时刻到 (prepMinutes > 0)
    SCHEDULED --> EATING : eat 时刻到 (prepMinutes == 0)
    PREPARING --> EATING : eat 时刻到
    EATING --> COMPLETED : 打卡 / 自动归档
    COMPLETED --> [*]
```

## 6. 提醒触发与调度

```mermaid
flowchart TD
    A["AlarmManager 精确闹钟触发"] --> R["AlarmReceiver"]
    R --> P["解析 alarm 参数<br/>mealId + phase(PREP/EATING)"]
    P --> M["查 Meal 记录"]
    M --> V{"计划仍有效?"}
    V -- 否 --> C["取消 / 忽略"]
    V -- 是 --> CH["ReminderChannel.trigger(meal, phase)"]
    CH --> N["发通知 + 轻短震动(~80ms)<br/>文案取自 SpeechCatalog"]
    N --> MK["标记该 phase 已通知(去重)"]
    MK --> W["刷新 Widget / 角色状态"]
```

## 8. 打卡流程（三入口汇流）

```mermaid
flowchart TD
    E1["入口1 · 通知动作按钮"] --> CI["CheckInUseCase.checkIn(date, mealType)"]
    E2["入口2 · App 内 / 日历点击"] --> CI
    E3["入口3 · 桌面 Widget 点击"] --> CI
    CI --> UP["UPSERT check_ins<br/>(date+mealType 幂等)"]
    UP --> LK{"当日有对应 Meal?"}
    LK -- 是 --> CP["Meal.status = COMPLETED"]
    LK -- 否 --> RF["直接刷新"]
    CP --> RF["Flow 驱动刷新 (SSOT)"]
    RF --> O1["记录页（统计概览 + 日历）"]
    RF --> O2["桌面 Widget"]
```

## 9. 角色状态派生

```mermaid
flowchart TD
    N["now = 当前时间"] --> H{"今日有计划?"}
    H -- 否 --> IDLE["IDLE 待机<br/>呼吸 + 眨眼"]
    H -- 是 --> P{"now 处于哪个阶段?"}
    P -- 到达 prepTime --> PREP["PREP 备餐<br/>切菜 / 颠锅"]
    P -- 到达 mealTime --> EAT["EATING 进食<br/>吃饭 / 咀嚼"]
    P -- 两餐之间 / 窗口外 --> FAST["FASTING 断食<br/>小跑 / 举铁 / 冥想"]
    P -- 三餐全完成 --> REST["REST 休息<br/>拉伸 / 比赞"]
    IDLE --> UI["首页角色帧动画 + 气泡"]
    PREP --> UI
    EAT --> UI
    FAST --> UI
    REST --> UI
```

## 10. 连续打卡统计（Streak）

```mermaid
flowchart TD
    IN["拉取近 N 天 check_ins"] --> G["按日期聚合为「完成日」集合"]
    G --> S["游标 = 今天(若未完成则昨天)"]
    S --> L{"游标那天是完成日?"}
    L -- 是 --> C["streak += 1<br/>游标 −= 1 天"] --> L
    L -- 否 --> O["输出 streak"]
```

> 说明：「完成日」= 当日三餐均存在 check_ins 记录；连续用 gap 检测，逻辑在 `domain/stats/` 纯函数，可单测。
